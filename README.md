# 🪄 HOGWARTS · Legacy of Magic

A fan-made 3D Harry Potter-inspired browser game built almost entirely inside a **single HTML file**.

Explore a dark magical world, fight enemies, cast spells, discover items, face bosses, and experience cinematic sequences — directly in your browser.

### ✨ Features

- 🏰 Fully 3D magical world
- ⚔️ Real-time combat & boss fights
- ✨ Spells and magical effects
- 🎒 Inventory, equipment & items
- ❤️ Health, magic and progression systems
- 🎬 Cinematic sequences
- 🗺️ Exploration and objectives
- 🎮 Keyboard + mouse controls
- 🌐 Runs directly in the browser
- 📄 Packed into a single HTML file

### 🚀 Running

Download `harry-potter.html` and open it in a modern desktop browser.
